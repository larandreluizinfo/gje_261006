## O jogo

Jogo 3D tipo Brawl Stars feito em **HTML, CSS e JavaScript (Three.js)**:
- Tela inicial com nome BRAWLMON + botão Jogar
- Escolha de personagem, começa com 1 brawler, complete missões para desbloquear os 65
- 65 brawlers com vida, arma, golpes e poder especial próprios
- 18 tipos: elétrico, fogo, água, planta, inseto, venenoso, gelo, fantasma, fada, dragão, aço, voador, psíquico, terrestre, pedra, sombrio, lutador, normal
- 3 modos: 🏈 Futebol, 💀 Sobrevivência e 💎 Pique-Gema
- Controles: WASD/setas + Espaço (atacar) + E (super) + botões touch
